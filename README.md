# 🛒 Lista de Desejos

## Sobre o projeto

Este projeto é uma **Lista de Desejos** desenvolvida com **HTML, CSS e JavaScript**.

Nele, o usuário pode cadastrar produtos que deseja comprar, informando:
- Produto
- Preço
- Quantidade
- Marca
- Onde comprar

Além disso, o sistema calcula automaticamente o valor total da compra com base no preço e na quantidade dos produtos.

## Funcionalidades

- Adicionar produtos.
- Editar produtos.
- Excluir produtos.
- Mostrar os produtos em uma tabela.
- Calcular o total de cada produto.
- Calcular o valor total da compra.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

O objetivo deste projeto é praticar os conceitos de CRUD, manipulação do DOM e programação em JavaScript de forma simples e organizada.
